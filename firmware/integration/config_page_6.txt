	! --- Misfire Detection (Engine State Machine sub-feature) ---
	! Tooth-timing misfire detection, active only while the SM reports Idle (lowest rotating
	! inertia = strongest combustion-torque signal). Each cylinder's expansion-stroke segment
	! time is measured and compared against ONE shared engine-wide baseline (a slow rolling
	! average of healthy segments) -- detection is NOT cylinder-specific. A firing is "flagged"
	! when its segment exceeds the adaptive threshold: baseline + misfireK * wobble, where
	! "wobble" is a second slow EMA tracking the typical spread of clean-firing durations
	! around the baseline. This self-calibrates sensitivity to the engine's own noise floor --
	! a smooth engine (low wobble) gets a tight threshold automatically; a lumpy cam or rough
	! idle (high wobble) gets a looser threshold and avoids false positives. To reject one-off
	! noise, a flagged firing is only counted once at least misfireConsecutiveCount flagged
	! firings have occurred within the last misfireWindowFirings firings (any cylinder). When
	! the cumulative counted total reaches misfireCountThreshold the generic OBD random/
	! multiple-cylinder misfire DTC (P0300) is thrown and held until power cycle. Misfire
	! detection's job ends at throwing that DTC -- whether/how the check-engine light itself
	! reacts to an active DTC is handled generically elsewhere (see Check Engine Triggering).
	! Set misfireCountThreshold to 0 to disable throwing the DTC entirely (monitor-only mode).
	bit misfireDetectionEnabled,"enabled","disabled";Misfire Detection: master enable. Detects misfires at idle (only while the Engine State Machine reports the Idle state) and throws the generic misfire DTC (OBD P0300) once the count threshold is reached. Detection is engine-wide, not per-cylinder.
	uint8_t misfireConsecutiveCount;Misfire Detection: minimum number of flagged firings that must fall within the recent-firings window (misfireWindowFirings) before a misfire is actually counted. This is a rate test over the whole engine, not one cylinder. Higher rejects more sporadic noise, but it must stay low enough relative to the window size and cylinder count to still trip on a single dead cylinder (a single dead cylinder produces roughly misfireWindowFirings divided by cylindersCount flags per window). Recommended N (with the matching window below) -- 4-cyl: 3, 6-cyl: 2, 8-cyl: 2.;"events", 1, 0, 1, 20, 0
	uint8_t misfireWindowFirings;Misfire Detection: length, in recent firings across all cylinders, of the sliding window the misfireConsecutiveCount rate test runs over. About two engine cycles is a good starting point. Recommended M (with the matching N above) -- 4-cyl: 12, 6-cyl: 12, 8-cyl: 16.;"firings", 1, 0, 1, 32, 0
	uint16_t misfireCountThreshold;Misfire Detection: total counted misfire events (engine-wide, accumulated since key-on) required before the misfire DTC (P0300) is thrown. Set to 0 to monitor only -- the misfireTotalCount gauge still accumulates but no DTC is ever set.;"events", 1, 0, 0, 10000, 0
	float misfireK;Misfire Detection: K multiplier for the wobble-based threshold. Threshold = baseline + K * wobble, where wobble is the engine's own rolling spread of clean-firing durations. Lower K is more sensitive. 3.0 is a good starting point for most engines.;"", 1, 0, 0.5, 20, 1

	! --- Aggressive Pressure Relief (PWM mode, returnless fuel systems) ---
	! On a returnless system the pump can only add fuel to the rail, never remove it - once
	! demand drops, excess pressure can only bleed off as the injectors consume it down, and
	! at low injected mass that happens too slowly for the PID's I-term to usefully chase
	! (it just winds down against a pump that already has no authority to help, then overshoots
	! low once pressure finally catches up). While this is enabled and injected fuel mass is
	! below fuelPumpReliefMaxInjectedMass, relief engages once pressure rises more than
	! fuelPumpReliefEngageOverpressure above target - pump duty is held at fuelPumpMinDuty
	! (bypassing PID output, PID reset) so pressure drains via consumption alone. Once engaged,
	! relief stays latched (hysteresis) until pressure falls back to within
	! fuelPumpReliefRecoverOverpressure of target, at which point normal PID control resumes.
	! fuelPumpReliefRecoverOverpressure should be set lower than fuelPumpReliefEngageOverpressure
	! (0 = resume only once pressure is back at or below target) to avoid chattering in/out of
	! relief right at the engage point.

	! --- Check Engine Triggering (MODULE_CHECK_ENGINE_LIGHT) ---
	! celPointsTotal sums a point for every currently-active check across the whole CheckEngineLight
	! module, not just the ones below: the TPS Circuit checks below (each worth a flat 1 point,
	! individually enabled here), Misfire Detection (misfire_detection.cpp keeps its own latch/DTC
	! path but also contributes a point here while latched), and CheckEngineLight's own
	! battery/MAP/IAT/TPS voltage-range checks (check_engine_light.cpp) -- those raise/clear their
	! DTCs immediately and unconditionally via addError()/removeError(), unrelated to
	! celPointsThreshold, but each also contributes a point here while its DTC is active. Every
	! slow-callback tick this combined total is summed and compared against the two thresholds
	! below. Reaching
	! celPointsThreshold (the lower of the two) raises the matching OBD code(s) via addError() and
	! lights the CEL solid -- the standard, less-urgent fault path. Reaching celBlinkPointsThreshold
	! (must be set higher) escalates that already-active DTC to a flashing CEL instead of the
	! normal digit-blink-out, matching OBD-II convention where a flashing MIL signals a more
	! critical, actively-damaging condition than a steady one. Set either threshold to 0 to disable
	! that stage. See check_engine_light.md.
	!
	! celDebounceTimeSec is shared by every check on this page: each check's trip condition must
	! hold continuously for this long before it trips, and be continuously clear for this long
	! before it untrips. TPS Circuit Intermittent also uses it as its flip-counting window.
	!
	! TPS Circuit Low/High (OBD_TPS1_Range_Performance) is implemented -- reuses the same TPS1
	! signal-out-of-range detection as the existing sensor_checker.cpp warning, just debounced
	! through celDebounceTimeSec and wired into addError()/celPointsTotal instead of only the
	! transient warning log. Deliberately a different OBD code than CheckEngineLight's own
	! OBD_TPS1_Primary_Low/High (raw-voltage range check on the Tps1Primary ADC channel) so the two
	! checks don't fight over the same DTC.
	! TPS Circuit Intermittent (P0124) is implemented -- trips when the TPS1 signal flips between
	! ok/fault at least tpsIntermittentFlipCount times within celDebounceTimeSec.
	!
	! Oil Pressure Low, Coolant Temp High, and AFR/Lambda Lean-or-Rich are reserved here (enable
	! bit only) but not yet evaluated -- their check-specific threshold fields will be added when
	! each is implemented. System Voltage Low/High is already implemented, but as one of
	! CheckEngineLight's always-on voltage-range checks above, not through voltageCelEnable below --
	! that bit remains reserved for a possible future check-specific variant.
