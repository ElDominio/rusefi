	! --- Misfire Detection (Engine State Machine sub-feature) ---
	! Tooth-timing misfire detection, active only while the SM reports Idle (lowest rotating
	! inertia = strongest combustion-torque signal). Each cylinder's expansion-stroke segment
	! time is measured and compared against ONE shared engine-wide baseline (a slow rolling
	! average of healthy segments) -- detection is NOT cylinder-specific. A firing is "flagged"
	! when its segment exceeds the adaptive threshold: baseline + misfireK * wobble, where
	! "wobble" is a second slow EMA tracking the typical spread of clean-firing durations
	! around the baseline. This self-calibrates sensitivity to the engine's own noise floor --
	! a smooth engine (low wobble) gets a tight threshold automatically; a lumpy cam or rough
	! idle (high wobble) gets a looser threshold and avoids false positives. To reject one-off
	! noise, a flagged firing is only counted once at least misfireConsecutiveCount flagged
	! firings have occurred within the last misfireWindowFirings firings (any cylinder). When
	! the cumulative counted total reaches misfireCountThreshold the generic OBD random/
	! multiple-cylinder misfire DTC (P0300) is thrown and held until power cycle. Misfire
	! detection's job ends at throwing that DTC -- whether/how the check-engine light itself
	! reacts to an active DTC is handled generically elsewhere (see Check Engine Triggering).
	! Set misfireCountThreshold to 0 to disable throwing the DTC entirely (monitor-only mode).
	bit misfireDetectionEnabled,"enabled","disabled";Misfire Detection: master enable. Detects misfires at idle (only while the Engine State Machine reports the Idle state) and throws the generic misfire DTC (OBD P0300) once the count threshold is reached. Detection is engine-wide, not per-cylinder.
	uint8_t misfireConsecutiveCount;Misfire Detection: minimum number of flagged firings that must fall within the recent-firings window (misfireWindowFirings) before a misfire is actually counted. This is a rate test over the whole engine, not one cylinder. Higher rejects more sporadic noise, but it must stay low enough relative to the window size and cylinder count to still trip on a single dead cylinder (a single dead cylinder produces roughly misfireWindowFirings divided by cylindersCount flags per window). Recommended N (with the matching window below) -- 4-cyl: 3, 6-cyl: 2, 8-cyl: 2.;"events", 1, 0, 1, 20, 0
	uint8_t misfireWindowFirings;Misfire Detection: length, in recent firings across all cylinders, of the sliding window the misfireConsecutiveCount rate test runs over. About two engine cycles is a good starting point. Recommended M (with the matching N above) -- 4-cyl: 12, 6-cyl: 12, 8-cyl: 16.;"firings", 1, 0, 1, 32, 0
	uint16_t misfireCountThreshold;Misfire Detection: total counted misfire events (engine-wide, accumulated since key-on) required before the misfire DTC (P0300) is thrown. Set to 0 to monitor only -- the misfireTotalCount gauge still accumulates but no DTC is ever set.;"events", 1, 0, 0, 10000, 0
	float misfireK;Misfire Detection: K multiplier for the wobble-based threshold. Threshold = baseline + K * wobble, where wobble is the engine's own rolling spread of clean-firing durations. Lower K is more sensitive. 3.0 is a good starting point for most engines.;"", 1, 0, 0.5, 20, 1
	float misfireWindowStart;Misfire Detection: window start, in degrees after each cylinder's TDC, where the expansion-torque deceleration is measured.;"deg", 1, 0, 0, 360, 0
	float misfireWindowEnd;Misfire Detection: window end, in degrees after each cylinder's TDC.;"deg", 1, 0, 0, 360, 0
	float misfireEmaAlphaDecel;Misfire Detection: EMA alpha when the segment line is ABOVE the baseline on the graph (longer duration, engine slowing). Controls how fast the baseline chases upward.;"", 1, 0, 0.001, 1, 3
	float misfireEmaAlphaAccel;Misfire Detection: EMA alpha when the segment line is BELOW the baseline on the graph (shorter duration, engine recovering). Controls how fast the baseline chases downward.;"", 1, 0, 0.001, 1, 3
	float misfireWobbleAlphaRise;Misfire Detection: wobble EMA alpha when the wobble line is climbing on the graph (spread increasing). Controls how fast the wobble chases upward.;"", 1, 0, 0.001, 1, 3
	float misfireWobbleAlphaFall;Misfire Detection: wobble EMA alpha when the wobble line is falling on the graph (spread decreasing). Controls how fast the wobble chases downward.;"", 1, 0, 0.001, 1, 3
